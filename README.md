# Manufacturing OEE & Efficiency Dashboard

## Project Overview
The **Plant Operations & OEE Monitor** is a Power BI project focused on analyzing manufacturing performance and operational efficiency.

The project aims to provide better visibility into production operations by tracking Overall Equipment Effectiveness (OEE), machine downtime, production performance, and product quality.

## Objectives
- Calculate Overall Equipment Effectiveness (OEE).
- Analyze machine availability and performance.
- Monitor product quality and rejection rates.
- Identify major downtime reasons.
- Analyze defect causes using Pareto analysis.
- Compare production efficiency across shifts and machines.

## Tools & Technologies
- Power BI
- DAX
- Microsoft Excel / CSV
- Data Cleaning and Data Analysis
- Data Visualization

## Key Metrics
1. **Availability:** Actual Run Time / Planned Production Time
2. **Performance:** Actual Output / Target Output
3. **Quality:** Good Count / Total Count
4. **OEE:** Availability × Performance × Quality

## Dashboard Analysis
The project requirements include:
- OEE performance monitoring
- Machine downtime analysis using a Gantt chart
- Defect analysis using a Pareto chart
- Actual vs. Target Production analysis
- Rejection rate monitoring
- Machine and shift performance comparisons

## Project Files
- `Manufacturing Dataset.csv` – Manufacturing dataset.
- `Manufacturing_final_DB.pbix` – Power BI dashboard file.
- `Manufacturing.docx` – Project requirement documentation.

## Business Questions
- Which machine delivers the highest OEE?
- Which shift operates most efficiently?
- What are the major reasons for product rejection?
- Does scrap rate increase with humidity or temperature?
- Which machines meet production targets but fail quality expectations?
- How does maintenance affect production quality?

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Explore the dashboard and its available filters and visualizations.
